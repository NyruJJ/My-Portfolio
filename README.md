# Nyru J. Jackson — Portfolio 3.0 / Dark Edition

This is the dark-only Portfolio 3.0 build. It retains the approved Signal Deck dark visual system, existing sections, navigation, content, and motion controls. The light theme and theme switch are not included.

## Experience background motion

The Experience chapter uses a broad teal spotlight in the upper-left and a slightly smaller one in the lower-right. Their glow expands and contracts gently; near the pointer, each light shifts toward it, grows, and brightens. The Animations On/Off control pauses the breathing motion.

## Run

Unzip the package and open `index.html` in Chrome or Firefox. For hosting, upload the directory contents to the static site's root.
